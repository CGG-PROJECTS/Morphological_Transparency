Morphological Transparency Norms

Large-scale estimates of semantic transparency and perceived morphological structure
for English polymorphemic words (Studies 1 & 2)

About these norms

This repository releases word-level morphological transparency estimates from two complementary studies.

  • Study 1 – Semantic distance between a derivation and its base word, following the classic 0–5 scale of Nagy & Anderson (1984).
  • Study 2 – Alignment between the number of morphemes listed in the English Lexicon Project (ELP) and the number of morphemes that readers typically perceive (Bernstein et al., 2020).

The two measures capture different dimensions of morphological transparency and can be used together to identify words that differ in both semantic inferability and structural perceptibility.

Data Dictionary

Study 1 – Semantic Distance Ratings

File: Study_1_Final_Data_Semantic_Distance_Ratings.csv

Variable Meaning
WORD Target polymorphemic word
BASEWORD Immediate base / ancestor of the target word
LLM_RATING_Semantic_Distance GPT-4.1-mini rating on the Nagy & Anderson (1984) 0–5 scale.
0–2 = transparent · 3–5 = opaque

Study 2 – LLM Transparency Estimates

File: Study_2_Final_Data_LLM_Transparency_Estimates.csv
Fine-tuned GPT-4.1-mini predictions trained on the crowdsourced data and extended to the full ELP.

Variable Meaning
Word Target polymorphemic word
Nmorph_ELP Number of morphemes listed in the English Lexicon Project (or supplemented source)
LLM_Predicted_Estimate Predicted number of morphemes people would typically perceive
Signed_Discrepancy_GPT_minus_NMorph LLM estimate − ELP count.
Positive = oversegmentation · Negative = undersegmentation
Absolute_Discrepancy Absolute size of the mismatch (|Signed Discrepancy|)
Transparency_Proximity_0_1 1 / (1 + Absolute_Discrepancy).
1 = perfect alignment · lower values = greater mismatch
Undersegmentation Amount by which the model predicts fewer morphemes than ELP (0 = none)
Oversegmentation Amount by which the model predicts more morphemes than ELP (0 = none)

Study 2 – Crowdsourced Morpheme Counting Task

File: Study_2_Final_Data_Crowdsourced_Morpheme_Counting_Task.csv
Human ratings collected from 176 adult participants (BLUP-adjusted).

Variable Meaning
Stimulus Target word
ELP_N_morphs Number of morphemes listed for the word in ELP (or supplemented source)
BLUP_Estimated_Score / BLUP_Adjusted_Morpheme_Count Participant-adjusted perceived morphological complexity from the BLUP model
Signed_Discrepancy_BLUP_minus_ELP Perceived count − ELP count.
Positive = participants perceived more morphemes · Negative = fewer
Absolute_Discrepancy Absolute distance between BLUP-estimated perceived count and ELP-listed count
Transparency_Proximity_0_1 1 / (1 + Absolute_Discrepancy). Higher values = closer alignment
Undersegmentation Amount by which participants perceived fewer morphemes than ELP (0 = none)
Oversegmentation Amount by which participants perceived more morphemes than ELP (0 = none)
BLUP_Rounded BLUP estimate rounded to the nearest whole morpheme
N / Crowdsourced_N Number of valid participant ratings for the word
Raw_Mean / Crowdsourced_Mean_Morpheme_Count Unadjusted mean of participant ratings
Raw_SD / Crowdsourced_Raw_SD Standard deviation of the raw ratings
Item_Rest_Cor Diagnostic correlation between ratings for this word and participants’ average ratings on other words
